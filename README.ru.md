# Напоминания о письмах для Thunderbird

[English](README.md) · **Русский**

Расширение позволяет назначать напоминания для писем и получать системные
уведомления при наступлении срока. Это [форк x09](https://github.com/x09/thunderbird-reminder-extension)
[оригинального проекта Marek Hajduczenia](https://github.com/gitzone83/thunderbird-reminder-extension)
с русской локализацией и механизмом добавления других языков.

## Скачать и установить

Текущая версия: **0.4.0.1**, на основе оригинального дополнения **0.4.0**.

- **[Скачать XPI 0.4.0.1](https://github.com/x09/thunderbird-reminder-extension/releases/download/v0.4.0.1/email-reminders-0.4.0.1-en-ru.xpi)**
- [Описание релиза и контрольная сумма SHA-256](https://github.com/x09/thunderbird-reminder-extension/releases/tag/v0.4.0.1)

В Thunderbird откройте **Дополнения и темы → шестерёнка → Установить дополнение
из файла** и выберите скачанный XPI. Для установки готового пакета Git, Python
и Node.js не нужны.

**Если установлен наш форк 0.3.2:** установите новый XPI поверх него. Напоминания
и настройки сохраняются; перенос через JSON не требуется.

**Если установлен оригинал (включая 0.4.0) или наша старая сборка 0.3.1.1:**
сначала экспортируйте напоминания в JSON, отключите старое дополнение, установите
новый XPI и импортируйте JSON в его настройках. Настройки задайте заново.
Не включайте обе версии одновременно. Сохраните экспорт до проверки переноса.

- Полные словари **английского и русского языков**: по 102 сообщения. Переведены
  четыре страницы интерфейса, меню, уведомления, ошибки, подтверждения и метки.
- Автоматический выбор языка по языку интерфейса Thunderbird; английский остаётся резервным.

  название, внутренний ключ и цвет метки сохраняются.
- Перенос длинных подписей кнопок и меню отсрочки внутри прокручиваемого списка.
- Воспроизводимая сборка XPI и автоматические проверки без сторонних библиотек в расширении.

### Переход с 0.3.1.1 или оригинального дополнения

Прежняя сборка использовала идентификатор оригинала и могла заменяться его
англоязычным обновлением с addons.thunderbird.net. Начиная с версии 0.3.2 у форка свой идентификатор
`email-reminders@x09.github.io`, автор `x09` и ссылка на сайт форка.
В настройках старого дополнения экспортируйте напоминания в JSON, отключите его,
установите новый XPI и импортируйте JSON в настройках нового дополнения.
Сохраните экспорт до проверки перенесённых записей. Настройки задайте заново.
Не включайте оба дополнения одновременно: у них общие метки писем и возможны
дублирующиеся уведомления. Следующие версии форка устанавливаются вручную из GitHub Releases.

Краткое описание дополнения переведено. Полное описание доступно в настройках
в разделе «О расширении» и в этом README. Карточка оригинала в каталоге и её
отзывы принадлежат исходному проекту; наш форк их не изменяет.

## Возможности

- Назначение напоминания через контекстное меню письма: дата, время и необязательная заметка.
- Быстрый выбор: через час, через четыре часа, завтра в 09:00 или через неделю.
- Оранжевая метка **«Есть напоминание»** у писем с активными напоминаниями.
- Просмотр активных напоминаний через кнопку на панели и полного списка с фильтрами.
- Отсрочка, выполнение, отклонение, удаление и возобновление напоминаний.
- Экспорт и импорт в JSON; необязательное архивирование письма после создания напоминания.
- Локальное хранение данных. Подробнее: [PRIVACY.md](PRIVACY.md).

## Как на самом деле работают уведомления

Thunderbird должен быть запущен. Расширение проверяет сроки **раз в минуту**,
поэтому уведомление может появиться при следующей проверке, а не ровно в назначенную
секунду. При запуске приложения также проверяются просроченные напоминания.

Когда наступает срок ожидающего или отложенного напоминания, расширение вызывает
**системное уведомление рабочего стола** с заголовком, темой письма и отправителем.
Расположение, внешний вид, длительность показа и история уведомлений зависят от ОС
и окружения рабочего стола. Щелчок по уведомлению запускает попытку открыть исходное
письмо в Thunderbird.

После успешного вызова API уведомлений напоминание получает статус `notified`
— **«Срок наступил»**. Это означает, что уведомление было запрошено, а не что
пользователь обязательно его увидел. Повторно то же уведомление **не показывается**.
Для нового показа нужно **отложить** напоминание.

Постоянного окна напоминания и собственного звукового сигнала у расширения нет.
Возможный системный звук зависит от настроек рабочего стола. Если Thunderbird
закрыт в назначенное время, уведомление откладывается до следующего запуска.

Счётчик на кнопке панели имеет вид `ожидающие|сработавшие`: слева учитываются также
отложенные напоминания, справа — записи со статусом `notified`. Красная дата или
надпись «Просрочено» определяется временем и сама по себе не доказывает показ
уведомления. Для обновления данных при проверке статуса переоткройте окно списка
или всплывающую панель.

Если уведомление не появилось, проверьте столбец **«Статус»** в полном списке,
системные разрешения уведомлений Thunderbird и режим «Не беспокоить». Для повторного
показа уже сработавшее напоминание нужно отложить. Выполненные и отклонённые
напоминания можно возобновить.

## Языки и добавление переводов

Язык расширения определяется языком интерфейса Thunderbird. После его смены
перезапустите Thunderbird. Для неподдерживаемых языков используются английские
сообщения; формат дат и времени по-прежнему учитывает язык интерфейса. Темы писем,
отправители, заметки, внутренние значения статусов и сохранённые даты не переводятся.

Чтобы добавить язык, скопируйте `_locales/en/messages.json` в
`_locales/<код_языка>/messages.json`, переведите сообщения, сохранив ключи и
подстановки, и запустите проверку словарей. Полная инструкция на английском:
[LOCALIZATION.md](LOCALIZATION.md).

## Сборка и установка нашего форка

Для сборки нужны Git и Python 3; для проверок — Node.js 18 или новее.

```sh
git clone https://github.com/x09/thunderbird-reminder-extension.git
cd thunderbird-reminder-extension

node scripts/check-locales.mjs
node --test tests/i18n.test.cjs
python3 scripts/build-xpi.py --version 0.4.0.1
```

Установите `dist/email-reminders-0.4.0.1.xpi` через меню Thunderbird:
**Дополнения и темы → шестерёнка → Установить дополнение из файла**.
В XPI входят рабочие файлы расширения и лицензия. Скриншоты, тесты, документация
и служебные файлы Git исключаются. Без `--version` используется версия из манифеста.

Идентификатор форка: `email-reminders@x09.github.io`. Он отличается от оригинала
и не менялся с версии форка 0.3.2. Поэтому обновление форка сохраняет его данные,
а переход с оригинала требует переноса через JSON. Форк не получает обновления
оригинала из каталога Thunderbird; новые версии устанавливайте из Releases.

Для разработки выберите **Отладка дополнений → Загрузить временное дополнение**
и укажите `manifest.json`. Версия из официального каталога дополнений распространяется
отдельно; её наличие не означает, что она включает изменения нашего форка.

## Проверки и известные ограничения

- Пройдены проверки словарей и ссылок на сообщения, а также 8 тестов Node.js.
- Пройдены 12 браузерных сценариев: четыре страницы на русском, английском и при
  неподдерживаемом языке. В этих сценариях API Thunderbird заменены тестовыми реализациями.
- XPI установлен и активирован в отдельных тестовых профилях Thunderbird 159;
  проверены русский, английский и резервный английский перевод.
- Сравнительная проверка оригинальной и локализованной сборок показала системные
  уведомления в ALT Workstation 11.2 / Thunderbird 159 / KDE.

Манифест заявляет Thunderbird **106+**, но наши проверки выполнялись на **159**.
Более ранние версии и полный сценарий работы с реальным почтовым ящиком ещё требуют проверки.

Сохраняются два ограничения исходного проекта: интервал фоновой проверки жёстко
задан в одну минуту, несмотря на переключатель в настройках; быстрый выбор дня
и возобновление используют 09:00, несмотря на настройку времени по умолчанию.
Локализация не меняла эту логику. Повторяющиеся напоминания не реализованы.
